# 2023年度　共創学部 卒業要件チェッカー

九州大学共創学部（2023年度入学者・日本人学生）向けの卒業要件チェッカーです。
Campusmate の「成績照会」ページを保存した HTML を読み込むと、卒業要件の充足状況を自動判定します。

## 使い方

1. Campusmate の**成績照会**ページを開く
2. **Ctrl+S**（Mac は **Cmd+S**）で「Webページ、完全」として保存する
3. このページのアップロード欄に保存した `.html` ファイルをドラッグ&ドロップ / ファイル選択、または内容をコピー&ペーストして「チェックする」を押す

判定結果として、以下が表示されます。

- 全体サマリ（総修得単位数 / 124単位、不足単位、第2外国語の自動推定）
- **不足項目リスト**（要件ごとの修得/必要/不足と履修ヒント）
- 基幹教育・専攻教育の区分別進捗（プログレスバー）
- その他（振替）の内訳（A〜F / お・か・き・く と最適配分の明細）
- **科目別の扱いの一覧**（HTMLジャンル見出し / 扱われたバケット / 判定根拠 / 成績 / コード）
  - ジャンルとコードが食い違う科目は警告表示（ジャンル見出しを優先）
  - 判別不能な科目は「手動」でバケットを振り替え可能（再評価されます）
- 除外された科目（F/W など）

## 判定の仕組み

- **ジャンル優先**: 成績照会HTMLの区分見出し（「（共創）アプローチ科目」「フロンティア科目」など）を第一の判定材料に使います。科目コードが無い科目（他学部科目など）も正しく分類されます
- **コード/科目名フォールバック**: 見出しが無いHTMLや未知の区分では、科目コード（`KED-`/`ISI-`）や科目名（`〔人社〕`等・言語名）で判定します
- **第2外国語は自動判定**: 英語系（既定 `KED-LCB11`/`KED-LCB21`）以外の言語科目をすべて第2外国語として合算し、超過分は「その他（B）= 基幹教育科目その他」に算入します
- **その他の最適配分**: 総合科目（D/い）・高年次超過（E/う）・他学部科目（F/え）は基幹その他（8.5単位）と専攻その他（12単位）のどちらにも充当でき、両方を満たせるよう自動配分します
- 他学部科目は上限10単位、協働科目の超過は上限2単位まで算入

## 開発・テスト

```bash
npm test          # node --test で全テスト実行（Node 18+、依存パッケージ不要）
```

テストには合成ケース（農学部・留学認定・コード無し科目・全角/半角成績・列順入替など）に加え、ローカルに `Campusmate.html`（成績照会の保存HTML・個人データのためGit非管理）があれば実HTMLの統合テストも実行されます（無い場合はスキップ）。

## GitHub Pages での公開

ビルド不要の静的サイトです。

1. このディレクトリを GitHub リポジトリに push
2. リポジトリの **Settings → Pages** を開く
3. 「Deploy from a branch」で `main` ブランチのルート（`/`）を選択して Save

公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）で利用できます。

ローカルで確認する場合:

```bash
python3 -m http.server 8080
# http://localhost:8080 を開く
```

（ポート 8080 も使用中の場合は 8123 など任意の番号に変更してください）

## 注意事項

- このツールの判定は**卒業要件の確認を支援するものであり、公式の判定ではありません**。最終確認は教務担当・「学生の手引」で行ってください
- 再履修などで同一科目が複数回表示される場合は全行を合算します（成績照会の表示による）
- 10月入学生（第1外国語＝日本語）や留学生の特別扱いには対応していません（日本人学生・4月入学生向け）
- 新しい科目区分（例: フロンティア科目・オープン科目は総合科目扱い）は手動振替で対応できます
